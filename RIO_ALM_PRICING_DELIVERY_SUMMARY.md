## 🔧 Technical Features

### State Management
```javascript
const [region, setRegion] = useState(null);           // 'inr' or 'usd'
const [expandedPlan, setExpandedPlan] = useState(null);  // Which plan expanded
const [expandedFaq, setExpandedFaq] = useState(null);    // Which FAQ expanded
```

### Geolocation Logic
```
1. Check localStorage for saved region
2. If found → use it
3. If not → call ipapi.co/json/
4. Get country_code from response
5. If country === 'IN' → default 'inr'
6. Else → default 'usd'
7. Save choice to localStorage
8. Fallback: 'usd' if API fails
```

### Price Display Logic
```
Show based on current region state
INR config.plans[key].price (e.g., "3,49,000")
USD config.plans[key].price (e.g., "4,500")
Update instantly on region toggle
```

### Accordion Logic
```
Plan details: Click toggles expandedPlan to/from that plan's key
FAQ: Click toggles expandedFaq to/from that FAQ's index
Only one accordion open at a time per type
Content animates in/out with slideDown keyframe
```
