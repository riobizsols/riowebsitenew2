## 🔧 How to Customize

### Change Content
1. **Landing**: Edit `RioALMLanding.jsx`
   - Update `keyFeatures` array
   - Update `outcomes` array
   - Update `faqs` array

2. **Features**: Edit `RioALMFeatures.jsx`
   - Update `featureGroups` array

3. **Industries**: Edit `RioALMIndustries.jsx`
   - Update `industries` array

4. **Deployment**: Edit `RioALMDeployment.jsx`
   - Update deployment descriptions and tables

5. **Contact**: Edit `RioALMContact.jsx`
   - Update company contact info
   - Connect form to backend

### Change Colors
Edit `src/components/Products/*.css` files:
```css
/* Old */
background: linear-gradient(135deg, #003d82 0%, #0052cc 100%);

/* New */
background: linear-gradient(135deg, #YOUR_COLOR 0%, #YOUR_COLOR 100%);
```

### Add More Content
1. Create new component in `src/components/Products/ComponentName.jsx`
2. Create matching CSS file
3. Add route to `src/App.js`
4. Update navbar if needed
